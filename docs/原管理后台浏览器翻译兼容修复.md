旧管理页切换菜单时出现前端 `removeChild` DOMException，随后由 React 错误边界显示“500”。这不是仅凭错误页就能认定的服务器 HTTP 500 或数据库异常。

证据指向浏览器翻译重写 React 管理的文本节点：React 后续删除其原先持有的节点时，该节点已经不在原父节点中。相同错误与触发方式见 [React 官方问题记录](https://github.com/react/react/issues/11538)。尚未完成同一线上会话关闭翻译后的对照验证，因此不声称排除了所有扩展干扰或其他 DOM 修改来源。
